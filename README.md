# GOGOMusic! 
Grazie al fenomeno dell’interconnessione digitale e alla popolarizzazione delle piattaforme di streaming musicali (es. Spotify) è più facile che mai conoscere nuovi artisti e generi. Questo ha consentito ad artisti internazionali di creare *fanbase* in ogni angolo del mondo, portando a tour mondiali di successo.

**GOGOMusic!** è un sito di booking che permette di cercare e acquistare biglietti per festival musicali.

## Funzionalità del sito

### Guest
  - Registrazione
  - Ricerca biglietti in base a filtri e categorie
  - Aggiunta e rimozione dal carrello dei biglietti

### Utente registrato
  - Autenticazione
  - Logout
  - Modifica informazioni personali
  - Ricerca biglietti in base a filtri e categorie
  - Aggiunta e rimozione dal carrello dei biglietti
  - Finalizzazione acquisto
  - Visualizzazione lista ordini
  - Annullamento ordine
    
### Amministratore
  - Aggiunta, modifica ed eliminazione eventi
  - Gestione ordini

## Setup
  1. Clona il repository
```
git clone https://github.com/annelabit/GOGOMusic
```
  2. Apri il progetto su Eclipse
  3. Avvia il server Tomcat
  4. Avvia il progetto su localhost
